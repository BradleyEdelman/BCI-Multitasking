# BCI Multitasking Analysis  

This repository contains the real-time software, and analysis and visualization scripts for studying multitasking using an EEG-based brain-computer interfaces (BCIs).

This study used a **modified version** of the **real-time BCI platform** described in:  
📂 **[BCI Real-Time Neuroimaging Repository](https://github.com/BradleyEdelman/BCI-real-time-neuroimaging)**  
📄 **[Science Robotics Paper](https://www.science.org/doi/full/10.1126/scirobotics.aaw6844)**  

---

## 📄 Related Publication  

### **Exploring Cognitive Flexibility With a Noninvasive BCI Using Simultaneous Steady-State Visual Evoked Potentials and Sensorimotor Rhythms**  
**B. J. Edelman et al., IEEE Transactions on Neural Systems and Rehabilitation Engineering, 2018**  
- Investigates how well users can **multitask** during EEG-based BCI control.
- **Key contributions:**  
  - Developed a **BCI framework** for simultaneous sensorimotor rhythma nd SSVEP signal analysis.  
  - Showed that **task complexity affects BCI performance** and user control.  
  - Identified dual-task features that facilitate or hinder performance.  

📄 [Read the full paper](https://ieeexplore.ieee.org/abstract/document/8323419)
